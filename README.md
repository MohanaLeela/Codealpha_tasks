This repository contains Python projects completed as part of my CodeAlpha Python Programming Internship (November 2026 Batch).

The projects demonstrate Python programming fundamentals and practical problem-solving skills.

## Projects

### 1. Hangman Game
A text-based word guessing game where the player guesses a randomly selected word within a limited number of attempts.

**Concepts Used:** Loops, Lists, Strings, Conditional Statements and Random Module.

### 2. Stock Portfolio Tracker
A Python application that calculates the total investment value based on stock prices and quantities entered by the user.

**Concepts Used:** Dictionaries, Lists, Loops, Arithmetic Operations and File Handling.

### 3. Basic Chatbot
A simple rule-based chatbot that interacts with users and provides predefined responses.

**Concepts Used:** Functions, Conditional Statements, Loops and Strings.
