**# Stock Portfolio Tracker**



**## 1. Project Overview**

**Stock Portfolio Tracker is a Python-based application developed as part of the CodeAlpha Python Programming Internship.**



**The program calculates the total investment value based on the stock names, stock prices, and quantities entered by the user.**



**It uses a predefined dictionary containing stock names and their corresponding prices.**



**## 2. Objectives**

**- Understand dictionary operations in Python.**

**- Perform basic financial calculations.**

**- Accept and process user input.**

**- Learn basic file handling.**



**## 3. Features**

**- Displays a list of available stocks and their prices.**

**- Allows users to enter stock names.**

**- Accepts the quantity of stocks purchased.**

**- Calculates individual investment values.**

**- Calculates the total investment value.**

**- Displays the portfolio summary.**

**- Saves investment details in a text file.**



**## 4. Technologies Used**

**- Programming Language: Python**

**- Editor: Visual Studio Code**

**- File Format: TXT**



**## 5. Python Concepts Used**

**- Dictionaries**

**- Lists**

**- Variables and Data Types**

**- For Loops**

**- If-Else Statements**

**- Arithmetic Operations**

**- File Handling**



**## 6. How to Run**

**1. Install Python on your computer.**

**2. Open the project folder in VS Code.**

**3. Open the terminal.**

**4. Execute the following command:**



**python stock\_portfolio\_tracker.py**



**## 7. Expected Result**

**The program displays available stocks and their prices.**

**The user enters stock names and quantities.**

**The application calculates the investment value and displays the total investment.**



**The portfolio details are saved in portfolio.txt.**



**Note: Stock prices are predefined example values and are not live market prices.**
