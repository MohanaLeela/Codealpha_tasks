**# Basic Chatbot**



**## 1. Project Overview**

**Basic Chatbot is a simple rule-based conversational application developed using Python as part of the CodeAlpha Python Programming Internship.**



**The chatbot interacts with users through text input and provides predefined responses based on the messages entered by the user.**



**It uses conditional statements and functions to process messages and generate appropriate responses.**



**## 2. Objectives**

**- Understand the working of a basic chatbot.**

**- Learn Python functions and conditional statements.**

**- Implement user interaction through input and output.**

**- Develop a simple conversational application.**



**## 3. Features**

**- Responds to greetings such as Hello and Hi.**

**- Answers predefined questions.**

**- Provides predefined replies.**

**- Supports continuous conversation.**

**- Ends the conversation when the user enters "bye".**



**## 4. Technologies Used**

**- Programming Language: Python**

**- Editor: Visual Studio Code**



**## 5. Python Concepts Used**

**- Functions**

**- if-elif-else Statements**

**- While Loop**

**- Strings**

**- String Methods**

**- User Input and Output**

**- Return Statement**

**- Break Statement**



**## 6. How to Run**

**1. Install Python on your computer.**

**2. Open the project folder in VS Code.**

**3. Open the terminal.**

**4. Execute the following command:**



**python chatbot.py**



**## 7. Expected Result**

**The chatbot welcomes the user and accepts text messages.**

**It checks the entered message and displays a predefined response.**

**The conversation continues until the user types "bye".**
