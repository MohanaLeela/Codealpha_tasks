**# Hangman Game**



**## 1. Project Overview**

**Hangman Game is a simple text-based word guessing game developed using Python as part of the CodeAlpha Python Programming Internship.**



**In this game, the computer randomly selects a word from a predefined list of five words. The player must guess the hidden word by entering one letter at a time.**



**The player is allowed a maximum of six incorrect guesses to find the correct word.**



**## 2. Objectives**

**- Develop an interactive word guessing game.**

**- Understand Python programming fundamentals.**

**- Practice conditional statements and loops.**

**- Implement random word selection.**



**## 3. Features**

**- Contains five predefined words.**

**- Randomly selects a secret word.**

**- Allows letter-by-letter guessing.**

**- Displays correctly guessed letters.**

**- Limits incorrect guesses to six.**

**- Prevents repeated guesses.**

**- Displays winning or losing messages.**
